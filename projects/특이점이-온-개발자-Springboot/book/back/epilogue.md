# 에필로그

시간이 지나 학기가 끝났고, 오픈이는 과제를 무사히 제출했습니다.

제출하기 전, 완성된 프로젝트를 처음부터 다시 훑어보았습니다. 과제를 시작할 때만 해도 어디서부터 손대야 할지 막막했습니다. 웹 서버 기능을 설정하느라 시간을 다 보내고, 정작 게시글 기능은 시작도 못 한 채 모니터 앞에서 한숨만 쉬기도 했습니다.

하지만 지금의 프로젝트는 스프링 프레임워크 위에서 완성되었습니다. 웹 서버의 기본 뼈대는 스프링에 맡기고, 핵심 기능 구현에만 집중하면 되었습니다.

게시판을 만드는 동안에도 어려운 순간은 있었습니다. 예외 처리가 제대로 되지 않아 당황했던 순간, 사용자 인증을 위해 낯선 개념을 공부하던 순간, 게시글에서 댓글을 가져올 방법이 없어 직접 SQL을 써야 하나 고민하던 순간도 있었습니다. 그때마다 문제를 하나씩 해결해 가며 코드를 완성했습니다.

다음에 만들 프로젝트는 이번 과제보다 훨씬 어려울 것입니다. 하지만 걱정은 없습니다. 상상하던 기능을 실제로 동작하는 코드로 처음부터 끝까지 완성해 본 경험이 남았기 때문입니다.

과제를 제출한 오픈이는 방학 동안 만들어 보고 싶은 아이디어를 적어 둔 수첩을 가방에 넣고, 가벼운 발걸음으로 건물을 나섭니다.
