# 소스코드 준비

이 책의 실습 코드는 두 저장소로 제공됩니다. 시작하기 전에 두 저장소를 한 번만 클론해 두면, 챕터마다 해당 폴더로 이동해 바로 실습할 수 있습니다.

```bash [터미널] 예제 저장소 클론
git clone https://github.com/metacoding/spring-start.git
git clone https://github.com/metacoding/spring-end.git
```

| 저장소 | 용도 |
|--------|------|
| spring-start | 책의 실습을 위해 사용합니다 |
| spring-end | 완성 코드를 확인할 수 있습니다 |

두 저장소 모두 챕터별 폴더로 나뉘어 있습니다.

| 챕터 | 폴더 | 주제 |
|------|------|------|
| 챕터 1 | `ch01` | 리플렉션과 컴포넌트 스캔 (순수 자바) |
| 챕터 2 | `ch02` | 게시판 CRUD와 JPA |
| 챕터 3 | `ch03` | 예외 처리와 DTO |
| 챕터 4 | `ch04` | 인증과 인가 |
| 챕터 5 | `ch05` | 댓글과 JPA 심화 |

`spring-start`의 각 폴더는 핵심 로직 자리가 비어 있습니다. 챕터를 따라 코드를 채우고, 막히면 `spring-end`의 같은 폴더에서 완성 코드를 확인하세요.

챕터 1은 스프링 프로젝트가 아니라 순수 자바입니다. 빌드 도구 없이 IDE에서 각 `App.java`의 `main` 메서드를 실행합니다. 챕터 2부터는 스프링 부트 프로젝트이고, 실행과 데이터베이스 설정은 챕터 2에서 함께 다룹니다.
