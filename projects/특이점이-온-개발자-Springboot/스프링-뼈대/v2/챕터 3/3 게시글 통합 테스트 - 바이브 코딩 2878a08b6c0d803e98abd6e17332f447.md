# 3. 게시글 통합 테스트 - 바이브 코딩

게시글 통합 테스트부터 CURSOR AI의 기능을 활용해 바이브 코딩으로 작성해보겠습니다.

# 3.1 바이브 코딩(Vibe Coding)이란?

> **바이브 코딩(Vibe Coding)이란 대규모 언어 모델(LLM)을 활용하여 자연어 프롬프트를 통해 코드를 생성하는 새로운 소프트웨어 개발 방식입니다.**
> 

바이브 코딩(Vibe Coding)은 누구나 손쉽게 사용할 수 있고, 빠른 속도로 결과를 도출할 수 있다는 장점이 있습니다. 다만, 불필요하거나 비효율적인 코드가 생성될 수 있으며, 개발자가 코드의 구조나 동작 원리를 충분히 이해하지 못한 경우 문제 발생 시 디버깅이 어려워질 수 있습니다.

따라서 바이브 코딩은 간단한 프로토타입 제작이나 기능 검증 단계에서 활용할 때 특히 효과적이며, 이러한 과정을 통해 개발 속도와 생산성을 크게 높일 수 있습니다.

효과적인 바이브 코딩을 위해 프롬프트를 다음의 내용을 포함해 작성하면 좋습니다.

> **1. 역할 :** AI의 역할을 설정합니다.
**2. 맥락 :** 답변에 대한 상황이나 배경을 작성합니다.
**3.** **지시 사항 :** 구체적으로 수행할 내용을 작성합니다.
**4. 제약 :** 반드시 지켜야할 조건을 작성합니다.
**5.** **결과 형식 :** 결과를 나타낼 형태를 설정합니다.
>

                                .password("1234")
                                .email("ssar@metacoding.com")
                                .roles("USER")
                                .build();
                accessToken = JwtUtil.create(testUser);
        }

        // 게시글 목록 조회 성공
        @Test
        public void findAll_success_test() throws Exception {
                // given
                **// when
                ResultActions result = mvc.perform(
                                MockMvcRequestBuilders.get("/api/boards")
                                                .header("Authorization", accessToken));
                // then
                result.andExpect(status().isOk())
                                .andExpect(jsonPath("$.status").value(200))
