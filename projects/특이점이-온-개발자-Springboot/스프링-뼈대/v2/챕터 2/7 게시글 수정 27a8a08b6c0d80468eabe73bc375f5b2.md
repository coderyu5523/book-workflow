# 7. 게시글 수정

# 7.1 BoardRequest

사용자가 수정한 내용을 전달 받기 위해 UpdateDTO를 구현합니다.

**BoardRequest.java**

```java
public record UpdateDTO(
        @Size(min = 1, max = 30, message = "제목은 1자 이상 30자 이하로 입력해주세요") 
        @NotEmpty(message = "제목을 입력해주세요") String title,

        @Size(min = 1, max = 300, message = "내용은 1자 이상 300자 이하로 입력해주세요") 
        @NotEmpty(message = "내용을 입력해주세요") String content) {
}
```

# 7.2 BoardService

그리고 BoardService에 게시글수정 메서드를 작성합니다. 

**BoardService.java**

```java
@Transactional
public BoardResponse.DTO 게시글수정(BoardRequest.UpdateDTO requestDTO, Integer boardId, Integer sessionUserId) {
    Board findBoard = boardRepository.findById(boardId).orElseThrow(() -> new Exception404("게시글을 찾을 수 없습니다"));
    if (!findBoard.getUser().getId().equals(sessionUserId))
        throw new Exception403("게시글을 수정할 권한이 없습니다");
    findBoard.update(requestDTO.title(), requestDTO.content());
    return new BoardResponse.DTO(findBoard);
}
```

update 메서드는 Board 엔티티 내부에 구현되어 있습니다.

# 7.3 BoardController

BoardController에 update 메서드를 다음과 같이 구현합니다. 

**BoardController.java**

```java
@PutMapping("/{boardId}")
public ResponseEntity<?> update(@AuthenticationPrincipal User sessionUser, @PathVariable("boardId") Integer boardId,
        @Valid @RequestBody BoardRequest.UpdateDTO requestDTO, Errors errors) {
    var responseDTO = boardService.게시글수정(requestDTO, boardId, sessionUser.getId());
    return Resp.ok(responseDTO);
}
```

HTTP Body에 수정할 게시글 정보를 담아 API를 호출하면, 정상적으로 업데이트된 결과를 응답 받을 수 있습니다.
