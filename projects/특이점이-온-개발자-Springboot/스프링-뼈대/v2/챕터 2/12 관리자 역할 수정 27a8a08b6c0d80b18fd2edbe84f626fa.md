# 12. 관리자 역할 수정

이번 장에서는 역할을 수정할 수 있는 기능을 구현해보겠습니다.

# 12.1 UserRequest

UserRequest 내부에 RolesDTO 클래스를 작성합니다. 이 클래스는 관리자가 설정한 사용자 역할 정보를 담습니다.

**UserRequest.java**

```java
public record RolesDTO(
    @NotEmpty(message = "역할을 설정해주세요") String roles){
}
```

# 12.2 AdminService

AdminService에 관리자_역할수정 메서드를 구현합니다.
User 엔티티의 roles 컬럼은 USER,ADMIN처럼 여러 권한을 가질 수 있으므로, 중복 여부 확인 시 콤마로 분리하여 배열에 담아 비교합니다.

**AdminService.java**

```java
@Transactional
public AuthResponse.DTO 관리자_역할수정(Integer userId,UserRequest.RolesDTO requestDTO){
    User findUser = userRepository.findById(userId)
    .orElseThrow(() -> new Exception404("회원을 찾을 수 없습니다"));
    
		// 중복 체크 , SET 는 순서 상관없이 비교 가능
    Set<String> currentRoles = new HashSet<>(Arrays.asList(findUser.getRoles().split(",")));
    Set<String> requestedRoles = new HashSet<>(Arrays.asList(requestDTO.roles().split(",")));       
    if (currentRoles.equals(requestedRoles)) {
        throw new Exception403("동일한 역할로 수정할 수 없습니다");
    }
           findUser.updateRoles(requestDTO.roles());
    return new AuthResponse.DTO(findUser);
}
```

# 12.3 AdminController

AdminController에 rolesUpdate 메서드를 구현합니다. 이 메서드는 URL로 전달된 사용자 정보를 기반으로 사용자의 역할을 수정합니다.

**AdminControll.java**

```java
@PutMapping("/users/{userId}")
public ResponseEntity<?> rolesUpdate(@PathVariable("userId") Integer userId,
        @Valid @RequestBody UserRequest.RolesDTO requestDTO, Errors errors) {
    var responseDTO = adminService.관리자_역할수정(userId,requestDTO);
    return Resp.ok(responseDTO);
}
```

사용자 cos의 JWT로 API 요청을 보내면, 해당 사용자의 역할이 정상적으로 수정된 것을 확인할 수 있습니다.
