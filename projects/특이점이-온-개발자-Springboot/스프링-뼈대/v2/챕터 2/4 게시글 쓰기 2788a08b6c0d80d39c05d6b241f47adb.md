# 4. 게시글 쓰기

# 4.1 BoardRequest

사용자 입력을 받기 위한 SaveDTO를 작성합니다. 이 DTO 내부에는 입력값을 Board 엔티티로 변환하는 toEntity() 메서드를 구현하여, 손쉽게 엔티티 객체를 생성할 수 있도록 합니다.

**BoardRequest.java**

```java
package com.metacoding.springv2.board;

import com.metacoding.springv2.user.User;
import jakarta.validation.constraints.*;

public class BoardRequest {
    public record SaveDTO(
            @Size(min = 1, max = 30, message = "제목은 1자 이상 30자 이하로 입력해주세요") 
            @NotEmpty(message = "제목을 입력해주세요") String title,

            @Size(min = 1, max = 300, message = "내용은 1자 이상 300자 이하로 입력해주세요") 
            @NotEmpty(message = "내용을 입력해주세요") String content) {
        public Board toEntity(User user) {
            return Board.builder()
                    .title(title)
                    .content(content)
                    .user(user)
                    .build();
        }
    }
}
```

# 4.2 BoardService

게시글쓰기 메서드를 작성합니다. 

사용자가 입력한 값은 SaveDTO의 toEntity() 메서드를 통해 Board 엔티티로 변환합니다. 이후, 변환된 엔티티를 JpaRepository의 save() 메서드에 전달하여 게시글을 저장합니다.

**BoardService.java**

```java
@Transactional
public BoardResponse.DTO 게시글쓰기(BoardRequest.SaveDTO requestDTO, User sessionUser) {
    Board savedBoard = boardRepository.save(requestDTO.toEntity(sessionUser));
    return new BoardResponse.DTO(savedBoard);
}
```

# 4.3 BoardController

BoardController에 save 메서드를 구현합니다. 클라이언트가 /api/boards로 요청을 보내면, 컨트롤러는 boardService를 호출해 게시글을 저장하고 그 결과를 응답으로 반환합니다.

**BoardController.java**

```java
@PostMapping
public ResponseEntity<?> save(@AuthenticationPrincipal User sessionUser,
        @Valid @RequestBody BoardRequest.SaveDTO requestDTO, Errors errors) {
    var responseDTO = boardService.게시글쓰기(requestDTO, sessionUser);
    return Resp.ok(responseDTO);
}
```

JWT를 포함해 API 요청을 보내면, 응답 데이터에 사용자가 입력한 게시글 정보가 함께 반환된 것을 확인할 수 있습니다.
