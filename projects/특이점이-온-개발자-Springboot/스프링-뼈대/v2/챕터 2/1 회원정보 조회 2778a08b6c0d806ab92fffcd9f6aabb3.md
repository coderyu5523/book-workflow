# 1.1 UserService

다음과 같이 UserService에 회원조회 메서드를 작성합니다. 

API URL에 포함된 회원 ID와 JWT에 저장된 회원 ID가 일치할 경우, 회원 정보를 DTO에 담아 응답합니다.

**UserService.java**

```java
public AuthResponse.DTO 회원조회(Integer userId, Integer sessionUserId) {
    if (!userId.equals(sessionUserId))
        throw new Exception403("조회 권한이 없습니다");
    User findUser = userRepository.findById(sessionUserId)
            .orElseThrow(() -> new Exception404("회원을 찾을 수 없습니다"));
    return new AuthResponse.DTO(findUser);
}
```

# 1.2 UserController

UserController에 getUser 메서드를 작성합니다.

클래스에 @RequestMapping를 사용해 공통 URL을 만들고, 각 메서드에서 상세 API URL 을 작성합니다. 즉 회원조회 API의 주소는  /api/users/1 이 됩니다.

> **@AuthenticationPrincipal은 Security Session에서 Authentication 객체를 꺼내 사용할 수 있는 어노테이션입니다. 이를 통해 스프링 시큐리티 내부가 아닌 서비스 계층에서 직접 인가 검증이 가능합니다.**
> 

**UserController.java**

```java
package com.metacoding.springv2.user;

import org.springframework.http.ResponseEntity;
import org.springframework.security.core.annotation.AuthenticationPrincipal;
import org.springframework.web.bind.annotation.*;
import com.metacoding.springv2.core.util.Resp;
import lombok.RequiredArgsConstructor;

@RequestMapping("/api/users")
@RequiredArgsConstructor
@RestController
public class UserController {

    private final UserService userService;

    @GetMapping("/{userId}")
    public ResponseEntity<?> getUser(@AuthenticationPrincipal User sessionUser,
            @PathVariable("userId") Integer userId) {
        var responseDTO = userService.회원조회(userId, sessionUser.getId());
        return Resp.ok(responseDTO);
    }
}
```
