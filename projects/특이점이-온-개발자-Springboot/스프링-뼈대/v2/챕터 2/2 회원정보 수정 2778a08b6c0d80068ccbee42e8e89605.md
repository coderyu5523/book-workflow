# 2. 회원정보 수정

# 2.1 UserRequest

사용자가 입력한 정보를 받을 UpdateDTO를  record 타입으로 작성합니다.

**UserRequest.java**

```java
package com.metacoding.springv2.user;

import jakarta.validation.constraints.*;

public class UserRequest {
    public record UpdateDTO(
            @Email(message = "이메일 형식이 올바르지 않습니다") String email,
            @NotBlank(message = "비밀번호를 입력해주세요") @Size(min = 4, max = 60, message = "비밀번호는 4~60자여야 합니다") String password) {
    }
}
```

우리는 챕터 1에서 엔티티를 작성할 때 @Getter 어노테이션만 적용하고, @Setter는 사용하지 않습니다. 이는 엔티티의 상태가 외부에서 임의로 변경되는 것을 막아 일관성과 무결성을 유지하기 위함입니다.

그래서 엔티티에서는 @Setter 대신 의도된 변경만 허용하기 위해 별도의 update 메서드를 정의했습니다.

# 2.2 UserService

UserService에 회원 수정 메서드를 작성합니다.
이때 sessionUserId로 조회한 User 엔티티에 대해,  update 메서드를 사용해 필요한 정보를 수정합니다.

**UserService.java**

```java
@Transactional
public AuthResponse.DTO 회원수정(UserRequest.UpdateDTO requestDTO, Integer sessionUserId) {
    User findUser = userRepository.findById(sessionUserId)
            .orElseThrow(() -> new Exception404("회원을 찾을 수 없습니다"));
    String encPassword = bCryptPasswordEncoder.encode(requestDTO.password());
    findUser.update(requestDTO.email(), encPassword);
    return new AuthResponse.DTO(findUser);
}
```

# 2.3 UserController

UserController에 updateUser 메서드를 작성합니다. 데이터 수정은 HTTP 메서드 중 PutMapping을 사용합니다.

**UserController.java**

```java
package com.metacoding.springv2.user;

import jakarta.validation.Valid;
import org.springframework.validation.Errors;

// 중략
@RequestMapping("/api/users")
@RequiredArgsConstructor
@RestController
public class UserController {

    private final UserService userService;

    @PutMapping
    public ResponseEntity<?> updateUser(@AuthenticationPrincipal User sessionUser,
            @Valid @RequestBody UserRequest.UpdateDTO requestDTO, Errors errors) {
        var responseDTO = userService.회원수정(requestDTO, sessionUser.getId());
        return Resp.ok(responseDTO);
    }
    // 중략
}
```
