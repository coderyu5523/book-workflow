# 10. 댓글 삭제

# 10.1 ReplyService

ReplyService에 댓글 삭제 메서드를 구현합니다. deleteById 메서드를 활용해 지정된 댓글을 삭제합니다.

**ReplyService.java**

```java
@Transactional
public void 댓글삭제(Integer replyId, Integer sessionUserId) {
    Reply findReply = replyRepository.findById(replyId)
            .orElseThrow(() -> new Exception404("댓글을 찾을 수 없습니다"));
    if (!findReply.getUser().getId().equals(sessionUserId))
        throw new Exception403("댓글을 삭제할 권한이 없습니다");
    replyRepository.deleteById(replyId);
}
```

# 10.2 ReplyController

ReplyController에 deleteById를 작성합니다. 삭제 성공 시 성공 상태와 함께 Body에 null을 반환합니다.

**ReplyController.java**

```java
@DeleteMapping("/{replyId}")
public ResponseEntity<?> deleteById(@AuthenticationPrincipal User sessionUser,
        @PathVariable("replyId") Integer replyId) {
    replyService.댓글삭제(replyId, sessionUser.getId());
    return Resp.ok(null);
}
```
