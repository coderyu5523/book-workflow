# 2. 프로젝트 생성 및 구조 세팅

IDE 프로그램은 CURSOR를 사용해 진행합니다.

# 2.1 스프링 프로젝트 생성

먼저 스프링 프로젝트 세팅하겠습니다. 

상단 탭 **View > Extensions**를 선택합니다.

**1.png**

확장 프로그램 중 **Extension Pack for java, Spring Boot Extension Pack**를 검색해 설치합니다.

![**2.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%201.png)

**2.png**

![**3.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%202.png)

설치가 완료되면 상단 탭 **View > Command Palette**를 선택합니다.

**4.png**

상단 탭 **View > Command Palette**를 선택 후 **Spring Initializr : Create a Gradle Project**를 실행합니다.

![**5.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%204.png)

**5.png**

아래의 설정으로 프로젝트를 생성합니다.

> **스프링 버전 : 3.5.5
언어 : Java
프로젝트 그룹ID : com.metacoding
Artifact ID(프로젝트명) : order
Packaging Type : JAR
Java 버전 : 21
dependencis : Spring Web, Lombok,  Spring Data JPA, H2 Database, Spring Security, Spring Rest Docs, JWT, Validation**
> 

CURSOR IDE는 스프링 프로젝트 생성 시 JWT 의존성이 조회가 되지 않습니다. 따라서 build.gradle에서 별도로 JWT에 대한 의존성을 추가해야 합니다.

```jsx
implementation group: 'com.auth0', name: 'java-jwt', version: '4.3.0'
```

프로젝트가 정상적으로 생성된 것을 확인할 수 있습니다.

# 2.2 패키지 세팅 및 파일 생성

springv2 폴더 아래에 **admin, auth, board, core, reply, user** 폴더를 생성합니다.

**src > main > java > com> metacoding > springv2**

![**7.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%206.png)

**7.png**

## 2.2.1 core 폴더

> **core 폴더는 프로젝트에 필요한 설정 파일 , 도구 파일 등을 모아 놓은 폴더입니다.**
> 

core 폴더에 config, filter, handler, util 폴더를 생성합니다. 

**src > main > java > com> metacoding > springv2 > core**

![**8.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%207.png)

**8.png**

config 폴더에는 설정 파일을 모아놓은 폴더입니다. **SecurityConfig.java** 파일을 생성합니다.

**src > main > java > com> metacoding > springv2 > core > config**

![**9.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%208.png)

**9.png**

filter 폴더는 스프링 필터와 관련된 파일을 모아놓은 폴더입니다. **JwtAuthorizationFilter.java** 파일을 생성합니다.

**src > main > java > com> metacoding > springv2 > core > filter**

![**10.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%209.png)

**10.png**

handler 폴더는 프로젝트의 오류와 유효성 처리와 관련된 파일을 모아놓은 폴더입니다. 
아래 그림과 같이 handler 폴더 아래에 **GlobalExceptionHandler.java** 와 **GlobalValidationHandler.java**  파일, **ex** 폴더를 생성합니다. 그리고 ex 폴더에는 예외 처리와 관련된 **Exception400, 401, 403, 404, 500.java** 파일을 생성합니다.

**src > main > java > com> metacoding > springv2 > core > handler**

![**11.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%2010.png)

**11.png**

util 폴더는 프로젝트에서 사용되는 도구 파일이 모여있는 폴더입니다.

**JwtProvider.java, JwtUtil.java, Resp.java, RespFilter.java** 파일을 생성합니다.

**src > main > java > com> metacoding > springv2 > core > util**

![**12.png**](2%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%83%9D%EC%84%B1%20%EB%B0%8F%20%EA%B5%AC%EC%A1%B0%20%EC%84%B8%ED%8C%85/image%2011.png)
