# 8. 유저네임 중복체크

이번 장에서는 회원가입 시 사전에 유저네임 중복 여부를 체크할 수 있는 기능을 구현해보겠습니다.

# 8.1 UserService

UserService에 유저네임중복체크 메서드를 작성합니다. 별도의 DTO 클래스를 만들지 않고, 자바의 Map 자료구조를 활용해 데이터를 반환합니다.

> **Map은 키와 값을 한 쌍으로 저장하는 구조이며, "available" 키에 유저네임 조회 결과를 값으로 담아 반환합니다.**
> 

**user/UserService.java**

```java
public Map<String, Object> 유저네임중복체크(String username) {
    Map<String, Object> mapDTO = new HashMap<>();
    if (userRepository.findByUsername(username).isPresent()) {
        mapDTO.put("available", false);
    } else {
        mapDTO.put("available", true);
    }
    return mapDTO;
}
```

# 8.2 AuthController

컨트롤러에 /check-username 요청을 처리하는 메서드를 작성합니다. GET 요청이므로 username 값은 쿼리 **스트링 형태(?key=value)**로 URL에서 전달받습니다.

**auth/AuthController.java**

```java
@GetMapping("/check-username")
public ResponseEntity<?> getUsername(@RequestParam String username) {
    var responseDTO = userService.유저네임중복체크(username);
    return Resp.ok(responseDTO);
}
```
