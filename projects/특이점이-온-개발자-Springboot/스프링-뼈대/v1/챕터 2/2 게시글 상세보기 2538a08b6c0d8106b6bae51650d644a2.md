# 2.1 BoardResponse

다음과 BoardResponse에 같이 DetailDTO 클래스를 구현합니다.

**BoardResponse.java**

```java
@Data
public static class DetailDTO {

    private Integer id;
    private String title;
    private String content;

    public DetailDTO(Board board) {
        this.id = board.getId();
        this.title = board.getTitle();
        this.content = board.getContent();
    }
}
```

# 2.2 BoardRepository

BoardRepository의 findById 메서드를 다음과 같이 수정합니다.

> **Spring Data JPA에서 `Optional`은 데이터 조회 결과가 존재하지 않는 경우 발생할 수 있는 `null` 관련 오류를 예방하기 위해 사용됩니다.**
> 

```jsx
public Optional<Board> findById(int id){       
    Board board = em.find(Board.class, id);
    return Optional.ofNullable(board);
 }
```

findById의 반환 타입을 Board에서 Optional<Board>로 수정합니다.

# 2.3 BoardService

BoardRepository에서 조회한 결과는 BoardService에서 Optional 타입으로 전달받습니다.

서비스 계층에서는 `Optional<Board>` 타입으로 그대로 처리할 수도 있고, `get()`이나 `orElseThrow()`와 같은 메서드를 사용해 조회 결과가 없는 경우를 예외로 처리할 수 있습니다.

> **get() 메서드는 Optional 클래스에 포함된 메서드로, 값이 존재한다고 가정하고 직접 꺼낼 때 사용합니다. 다만 값이 없을 경우 예외가 발생하기 때문에, 추후에 예외 처리를 위해 orElseThrow()  메서드로 대체해야 합니다.**
> 

`BoardService`에서 `findById` 메서드를 호출하는 메서드는`get()`을 사용해 `Optional` 값을 처리합니다.

**BoardService.java**

```jsx
public Board 게시글상세(Integer id) {
    Board board = boardRepository.findById(id).get();
    return board;
}

@Transactional
public void 게시글삭제(Integer id) {
    Board board = boardRepository.findById(id).get();
    boardRepository.delete(board);
}

public Board 게시글수정폼(Integer id) {
    Board board = boardRepository.findById(id).get();
    return board;
}

@Transactional
public void 게시글수정(Integer id, BoardRequest.UpdateDTO requestDTO) {
    Board board = boardRepository.findById(id).get();
    // 더티 체킹
    board.setTitle(requestDTO.getTitle());
    board.setContent(requestDTO.getContent());
} // 트랜잭션 종료시 flush()
```

그리고 게시글상세 메서드는 반환 타입을 BoardResponse.DetailDTO로 수정합니다.

**BoardService.java**

```java
public BoardResponse.DetailDTO 게시글상세(Integer id) {
    Board board = boardRepository.findById(id).get(); 
    BoardResponse.DetailDTO dto = new BoardResponse.DetailDTO(board); // DTO 담기기
    return dto;
}
```
