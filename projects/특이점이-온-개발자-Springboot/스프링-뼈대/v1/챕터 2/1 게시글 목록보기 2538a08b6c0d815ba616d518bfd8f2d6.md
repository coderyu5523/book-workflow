# 1.1 DTO(Data Transfer Object)

> **DTO(Data Transfer Object)는 계층 사이에서 계층 간 데이터 전달만을 목적으로 하는 객체입니다. 
서로 다른 계층 사이에서 필요한 데이터만 담아 전달할 수 있어 원하는 형태의 데이터 구조를 반환할 수 있습니다.**
> 

board 폴더에 BoardResponse.java 파일을 생성합니다. 이 클래스는 BoardRepository를 통해 전달받은 데이터를 담아 화면에 전송하는 역할을 합니다.

이제 데이터 전달을 담당하는 BoardResponse 클래스 내부에 정적(static) 내부 클래스인 DTO를 정의하겠습니다.

DTO의 모든 필드는 `private`으로 선언하여 캡슐화를 강화하고, 생성자는 `Board` 엔티티를 매개변수로 받아 엔티티의 필드 값을 DTO의 각 필드에 매핑하여 초기화합니다.

**BoardResponse.java**

```java
package com.metacoding.springv1.board;

import lombok.Data;

public class BoardResponse {

    @Data
    public static class DTO {

        private Integer id;
        private String title;
        private String content;

        public DTO(Board board) {
            this.id = board.getId();
            this.title = board.getTitle();
            this.content = board.getContent();
        }
    }   
}
```

> **STATIC 클래스는 바깥 클래스의 인스턴스와 독립적으로 동작하며, 별도의 외부 객체 생성 없이 어디서든 접근할 수 있습니다.
내부 필드는 private 으로 선언해 외부에서 직접 접근하지 못하도록 하고, Lombok의 @Data 어노테이션이 생성하는 Getter/Setter 메서드를 통해서만 값을 읽거나 수정할 수 있어 데이터가 안전하게 캡슐화됩니다.**
> 

# 1.2 BoardService

이제 DTO를 사용해 BoardRepository에서 조회한 데이터를 BoardService 에서 받아보겠습니다.

> **게시글은 다건 조회 결과이므로 List 타입으로 반환됩니다.**
> 
> 
> **따라서 반복문을 사용해 각 엔티티를 DTO에 담고, 이를 모아 새로운 List<DTO>를 생성합니다.**
> 

반환 타입을 List<Board> 에서 List<BoardResponse.DTO> 타입으로 수정합니다.

**BoardService.java**

```java
package com.metacoding.springv1.board;

import java.util.List;
import java.util.stream.Collectors;
import org.springframework.stereotype.Service;
import lombok.RequiredArgsConstructor;

@RequiredArgsConstructor
@Service
public class BoardService {

    private final BoardRepository boardRepository;

    public List<BoardResponse.DTO> 게시글목록() {

        List<Board> boards = boardRepository.findAll(); // board 엔티티 조회
        List<BoardResponse.DTO> dtoList = boards.stream()  
	            .map(board -> new BoardResponse.DTO(board))
	            .toList();
        return dtoList;
    }    
}
```

# 1.3 BoardController

BoardController도 반환 타입을 List<Board> 에서 List<BoardResponse.DTO> 타입으로 수정합니다.

**BoardController.java**

```java
@GetMapping("/")
public String index(HttpServletRequest request) {
    List<BoardResponse.DTO> boards = boardService.게시글목록();
    request.setAttribute("models", boards);
    return "index";
}
```
