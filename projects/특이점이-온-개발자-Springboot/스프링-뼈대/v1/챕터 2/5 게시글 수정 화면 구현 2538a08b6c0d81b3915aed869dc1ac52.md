# 5. 게시글 수정 화면 구현

# 5.1 Service

BoardService의 게시글수정폼 메서드의 반환 타입을 BoardResponse.DTO로 수정합니다.

**BoardService.java**

```java
public BoardResponse.DTO 게시글수정폼(Integer id) {
    Board board = boardRepository.findById(id).get();
    BoardResponse.DTO dto = new BoardResponse.DTO(board);
    return dto;
}
```

# 5.2 Controller

BoardController도 서비스의 반환 타입을 BoardResponse.DTO로 수정합니다.

**BoardController.java**

```java
@GetMapping("/boards/{id}/update-form")
public String updateForm(HttpServletRequest request, @PathVariable("id") Integer id) {
    BoardResponse.DTO board = boardService.게시글수정폼(id);
    request.setAttribute("model", board);
    return "board/update-form";
}
```

프로젝트를 실행한 후 게시글 수정 페이지로 이동하면, 기존과 동일한 결과를 확인할 수 있습니다.
