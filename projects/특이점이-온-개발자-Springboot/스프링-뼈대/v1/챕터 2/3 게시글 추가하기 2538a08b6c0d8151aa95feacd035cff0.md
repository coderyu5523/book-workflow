# 3. 게시글 추가하기

# 3.1 BoardRequest

다음과 같이 SaveDTO에 `toEntity()` 메서드를 추가합니다.

> **Spring에서 데이터를 저장하려면 엔티티를 영속화해야 합니다. 그러나 `SaveDTO`는 엔티티가 아니므로, 이를 `Board` 엔티티로 변환하기 위해 `toEntity()` 메서드를 정의합니다.**
> 

**BoardRequest.java**

```java
package com.metacoding.springv1.board;

import lombok.Data;

public class BoardRequest {

    @Data
    public static class SaveDTO {

        private String title;
        private String content;

        // 빌더 패턴으로 엔티티 생성
	      public Board toEntity() {
	        return Board.builder()
	            .title(title)
	            .content(content)
	            .build();
	      }
    }   
}
```

# 3.2 **BoardRepositoryTest**

`BoardRepositoryTest`의 `save_test` 메서드는 `toEntity()` 메서드와 동일하게, Builder 패턴을 사용해 엔티티를 생성하도록 수정합니다.

**BoardRepositoryTest.java**

```java
@Test
public void save_test() {
    // given
    Board board = Board.builder()
            .title("title3")
            .content("content3")
            .build();
    // when
    boardRepository.save(board);
    // eye
    List<Board> boards = boardRepository.findAll();
    System.out.println("=======================");
    System.out.println("Board Count : " + boards.size());
    System.out.println("Board ID: " + boards.get(2).getId());
    System.out.println("Board Title: " + boards.get(2).getTitle());
    System.out.println("Board Content: " + boards.get(2).getContent());
}

```

# 3.3 BoardService

BoardService는 `SaveDTO`의 `toEntity()` 메서드를 사용해 전달받은 요청 데이터를 엔티티로 변환한 뒤, 이를 저장합니다.
**BoardService.java**

```java
@Transactional
public void 게시글추가(BoardRequest.SaveDTO requestDTO) {
    Board board = requestDTO.toEntity(); // DTO -> 엔티티
    boardRepository.save(board);
}
```
