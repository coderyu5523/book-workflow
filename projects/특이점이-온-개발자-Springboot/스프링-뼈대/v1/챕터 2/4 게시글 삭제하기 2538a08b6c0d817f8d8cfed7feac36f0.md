# 4. 게시글 삭제하기

# 4.1 BoardService

> **게시글 삭제 로직은 2장에서 적용한 게시글삭제 메서드의 `Optional` 처리 내용을 제외하면 추가로 변경된 부분은 없습니다.**
> 

**BoardService.java**

```jsx
@Transactional
public void 게시글삭제(Integer id) {
    Board board = boardRepository.findById(id).get();
    boardRepository.delete(board);
}
```

# 4.2 **BoardRepositoryTest**

@Test
public void delete_test() {
