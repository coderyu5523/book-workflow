# 1.1 양방향 매핑 @OneToMany

> **양방향 매핑은 두 엔티티가 서로를 참조해 양쪽 방향으로 탐색할 수 있도록 하는 매핑 방식으로, 다수 엔티티는 @ManyToOne, 단일 엔티티에는 @OneToMany를 명시해줍니다.
이를 통해 게시글 엔티티에서 댓글 엔티티 에 접근할 수 있어 조회와 코드 작성이 훨씬 직관적이고 편리해집니다.**

다음과 같이 Reply 엔티티를 정의하며,  User 엔티티 와 Board 엔티티을 참조하는 필드를 포함합니다.

이렇게 하면 각 댓글이 어떤 회원이, 어떤 게시글에 작성했는지를 알 수 있습니다.

**Reply.java**

```java
package com.metacoding.springv1.reply;

import java.sql.Timestamp;

import org.hibernate.annotations.CreationTimestamp;

import com.metacoding.springv1.board.Board;
import com.metacoding.springv1.user.User;

import jakarta.persistence.*;
import lombok.*;

@NoArgsConstructor
@Data
@Entity  
@Table(name="reply_tb") 
public class Reply {
    @Id
    @GeneratedValue (strategy = GenerationType.IDENTITY) 
    private Integer id;
    private String comment;

    @ManyToOne(fetch = FetchType.LAZY)  // 외래키 필드
    @JoinColumn(name = "user_id") 
    private User user; 

    @ManyToOne(fetch = FetchType.LAZY) // 외래키 필드
    @JoinColumn(name = "board_id") 
    private Board board; 

    @CreationTimestamp 
    private  Timestamp createdAt;

    @Builder
    public Reply(Integer id, String comment, User user, Board board, Timestamp createdAt) {
        this.id = id;
        this.comment = comment;
        this.user = user;
        this.board = board;
        this.createdAt = createdAt;
    }
}
```

양방향 매핑을 위해 Board 엔티티에 Reply 컬렉션을 필드로 추가합니다. 게시글에 달린 댓글들을 한 번에 조회할 수 있도록 List 타입으로 선언합니다.

이때 @OneToMany 어노테이션을 사용하며, mappedBy 속성에는 Reply 엔티티에서 Board를 참조하고 있는 필드명을 지정해야 합니다.

**Board.java**

```java
package com.metacoding.springv1.board;

import java.sql.Timestamp;
import java.util.*;

import org.hibernate.annotations.CreationTimestamp; 

import com.metacoding.springv1.reply.Reply; // 추가
import com.metacoding.springv1.user.User;

import jakarta.persistence.*;
import lombok.*;

@NoArgsConstructor
@Data
@Entity  
@Table(name="board_tb") 
public class Board {
    @Id
    @GeneratedValue (strategy = GenerationType.IDENTITY)  
    private Integer id;
    private  String title;
    private  String content;

    @CreationTimestamp 
    private  Timestamp createdAt;

    @ManyToOne(fetch = FetchType.LAZY) 
    @JoinColumn(name = "user_id") 
    private User user; 

    @OneToMany(mappedBy = "board", fetch = FetchType.LAZY, cascade = CascadeType.REMOVE) // reply 필드 연결
    private List<Reply> replies = new ArrayList<>(); // List가 없으면 null이 아닌 0 반환

    @Builder
    public Reply(Integer id, String comment, User user, Board board, Timestamp createdAt) {
        this.id = id;
        this.comment = comment;
        this.user = user;
        this.board = board;
        this.createdAt = createdAt;
    }
}
```
