# 4.1 delete

ReplyRepository에 권한 체크를 위한 findById 메서드와 댓글 삭제를 delete 메서드를 구현합니다.

**ReplyRepository.java**

```java
//권한 체크 메서드
public Optional<Reply> findById(Integer id) {
    Reply reply = em.find(Reply.class, id);
    return Optional.ofNullable(reply);  
}

// 삭제 메서드
public void delete(Reply reply) {
    em.remove(reply);
}
```

# 4.3 Service

다음과 같이 댓글 삭제 기능을 구현합니다. 

먼저 댓글 작성자 ID와 세션 ID를 비교해 권한을 검증한 후, 조건을 만족하면 댓글을 삭제합니다.

> **댓글 삭제 후 게시글 상세보기 페이지로 리다이렉트를 위해 게시글ID를 반환합니다.**
> 

**ReplyService.java**

```java
@Transactional
public int 댓글삭제(Integer replyId, Integer sessionUserId) {
    Reply reply = replyRepository.findById(replyId).orElseThrow(() -> new Exception404("댓글을 찾을 수 없습니다."));
    if (reply.getUser().getId() != sessionUserId) {
        throw new Exception403("댓글을 삭제할 권한이 없습니다.");
    }
    replyRepository.delete(reply);
    return reply.getBoard().getId();
}
```

댓글 작성자가 아니라면 403 에러가 발생합니다.

컨트롤러의 deleteById 메서드는 서비스 실행 결과로 받은 boardId를 이용해 해당 게시글 상세보기 페이지로 리다이렉트합니다.

**ReplyController.java**

```java
@PostMapping("/replies/{id}/delete")
public String deleteById(@PathVariable("id") Integer id) {
    User sessionUser = (User) session.getAttribute("session");
    if(sessionUser == null){
        throw new Exception401("로그인이 필요합니다.");
    }
    int boardId = replyService.댓글삭제(id, sessionUser.getId());
    return "redirect:/boards/" + boardId;
}
```
