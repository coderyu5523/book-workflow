# 5. 전역 예외 처리

이전 챕터에서는 예외 메시지를 터미널 창에서만 확인했고, 브라우저 응답 처리는 다루지 않았습니다. 이번 챕터에서는 예외 발생 시 브라우저에서 안내 메시지와 페이지 이동 처리를 해보도록 하겠습니다.

# 5.1 alert창 띄우기

core 폴더에 util 폴더를 생성 후  Script.java 클래스를 생성합니다.

**springv1 > core > util**

![**1.png**](5%20%EC%A0%84%EC%97%AD%20%EC%98%88%EC%99%B8%20%EC%B2%98%EB%A6%AC/image.png)

**1.png**

다음과 같이 Script 클래스에 back 메서드를 구현합니다.  back 메서드는 HTML <script>를 생성해 예외 메시지를 alert창에 표시합니다.

> **history.back() 는 이전 페이지로 이동하는 자바스크립트 명령어입니다**
> 

**core/util/Script.java**

```java
package com.metacoding.springv1.core.util;

public class Script {

    public static String back(String msg) {
        StringBuilder sb = new StringBuilder();
        sb.append("<script>");
        sb.append("alert('"+msg+"');");
        sb.append("history.back();");
        sb.append("</script>");
        return sb.toString();
    }
}
```

다음으로 handler 패키지에 GlobalExceptionHandler.java 클래스를 생성합니다.

**springv1 > core > handler**

![**2.png**](5%20%EC%A0%84%EC%97%AD%20%EC%98%88%EC%99%B8%20%EC%B2%98%EB%A6%AC/image%201.png)

**2.png**

GlobalExceptionHandler 클래스에 myHandler 메서드를 구현합니다. 예외가 발생하면 해당 오류 메시지를 back 메서드로 전달하여 처리합니다.

> **@ControllerAdvice와 @ExceptionHandler를 함께 사용하면 애플리케이션 전역의 예외를 한 곳에서 일관되게 처리할 수 있습니다.**
> 

**core/handler/GlobalExceptionHandler.java**

```java
package com.metacoding.springv1.core.handler;
import org.springframework.web.bind.annotation.*;
import com.metacoding.springv1.core.util.Script;

@ControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(Exception.class) 
    @ResponseBody
    public String myHandler(Exception e){
        return Script.back(e.getMessage());
    }
}
```

# 5.2 페이지 이동

이번에는 alert 창과 페이지 이동을 같이 구현해보겠습니다. 다음과 같이 href 메서드를 구현합니다.

**core/util/Script.java**

```java
public static String href(String path, String msg) {
    StringBuilder sb = new StringBuilder();
    sb.append("<script>");
    sb.append("alert('"+msg+"');");
    sb.append("location.href='"+path+"';");
    sb.append("</script>");
    return sb.toString(); 
}
```

그리고 myHandler401 메서드를 구현합니다. 401 에러 발생시 로그인 페이지의 URL와 메세지를 href 메서드에 함께 전달합니다.

**core/handler/GlobalExceptionHandler.java**

```java
package com.metacoding.springv1.core.handler;

import org.springframework.web.bind.annotation.*;
import com.metacoding.springv1.core.handler.ex.Exception401;
import com.metacoding.springv1.core.util.Script;

@ControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(Exception401.class)
    @ResponseBody
    public String myHandler401(Exception401 e) {
        return Script.href("/login-form", e.getMessage());
    }
    // 중략
}
```
