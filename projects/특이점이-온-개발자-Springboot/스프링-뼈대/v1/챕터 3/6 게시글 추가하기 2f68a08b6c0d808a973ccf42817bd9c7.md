# 6.2 Service

> **@Transactional 은 트랜잭션의 시작과 끝을 정의하는 어노테이션입니다. 데이터의 입력, 수정, 삭제와 같은 작업이 포함된 로직이 모두 정상적으로 실행되면 자동으로 COMMIT 되고, 중간에 하나라도 실패하면 전체가 ROLLBACK 되어 데이터의 무결성과 일관성을 보장합니다.**
> 

BoardService 클래스에 게시글추가() 메서드를 정의합니다.  

컨트롤러에서 DTO를 매개변수로 받아, toEntity() 메서드를 통해  Board 엔티티로 변환 후 save() 메서드를 통해 데이터를 저장합니다.

**BoardService.java**

```java
package com.metacoding.springv1.board;

import java.util.List;
import java.util.stream.Collectors;
import org.springframework.stereotype.Service;
import jakarta.transaction.Transactional;
import lombok.RequiredArgsConstructor;

@RequiredArgsConstructor
@Service
public class BoardService {

    private final BoardRepository boardRepository;

    @Transactional
    public void 게시글추가(BoardRequest.SaveDTO requestDTO){
        Board board = new Board();
        board.setTitle(requestDTO.getTitle());
        board.setContent(requestDTO.getContent());
        boardRepository.save(board);
    }
		// 게시글목록, 게시글상세 중략    
}

```

# 6.4 Redirect

> **리다이렉트(redirect)는 ‘다시 요청을 보낸다’ 는 뜻으로, 서버가 요청을 처리한 뒤 브라우저에게 새 URL로 재요청하라고 지시하는 동작입니다. 보통 서버는 302 상태 코드와 새로운 주소를 응답으로 보내고, 브라우저는 그 주소로 새로운 HTTP 요청을 보냅니다.**
> 

BoardController 의 save() 메서드에서 반환값을 “redirect:/” 로 지정하면, 요청 처리 후 브라우저가 루트 경로(/)로 리다이렉트됩니다.

글쓰기 버튼을 클릭하면 리다이렉트되어 게시글 목록 페이지로 이동하며, 등록한 게시글도 목록에서 확인할 수 있습니다.

![**7.png**](6%20%EA%B2%8C%EC%8B%9C%EA%B8%80%20%EC%B6%94%EA%B0%80%ED%95%98%EA%B8%B0/image%206.png)

**7.png**

브라우저에서 F12를 눌러 Network > Headers를 확인하면, /boards/save 경로로 POST 요청 시 서버가 302 상태 코드를 반환하는 것을 볼 수 있습니다. 이는 리다이렉트를 의미하며, Response Headers의 Location 값에 지정된 루트 경로(/)로 이동하게 됩니다.
