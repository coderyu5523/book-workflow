# 1.3 **Controller와 화면 연결**

1.2 챕터에서 생성한 그림을 웹 페이지로 만들어보겠습니다. 그러기 위해 Controller에 페이지에 맞는 메서드를 생성해주어야 합니다.

아래의 그림과 같은 경로에 board 폴더를 생성 후 BoardController 파일을 생성합니다.

**scr > main > java > com > metacoding > springv1 > board**

![**6.png**](1%20%EB%B8%94%EB%A1%9C%EA%B7%B8%20%EB%BC%88%EB%8C%80%20%EB%A7%8C%EB%93%A4%EA%B8%B0%20%ED%99%94%EB%A9%B4%20%EC%84%A4%EA%B3%84/image%206.png)

**6.png**

아래와 같이 컨트롤러에 @Controller 어노테이션을 추가합니다. 이 어노테이션을 붙이면 스프링 프레임워크가 객체를 알아서 생성, 관리해줍니다.

> **@Controller와 같은 어노테이션은 이미 만들어진 라이브러리의 기능을 사용하는 것입니다.**
> 
> 
> **이 기능을 쓰려면 해당 라이브러리를 import하여 클래스 상단에 명시해야 하며, 그래야 필요한 기능을 코드에서 사용할 수 있습니다.**
> 

**board/BoardController.java**

```java
package com.metacoding.springv1.board;

import org.springframework.stereotype.Controller;  // 컴포넌트 스캔
import org.springframework.web.bind.annotation.*; // URL 매핑

@Controller
public class BoardController {
    // 메서드 입력
}
```

컨트롤러 내부의 메서드를 만들어보겠습니다.

먼저 메인 페이지를 만들어보겠습니다.  일반적으로 메인 페이지는 도메인 주소만 입력하면 연결되는 페이지입니다.  

클래스 내부에 아래와 같이 작성합니다. URI 속성 값은  / 를 넣습니다. 사용자의 요청을 받아 페이지를 반환하는 경우 @GetMapping 어노테이션을 사용합니다.

> **사용자의 요청을 매핑하기 어노테이션에는 @GetMapping, @PostMapping, @PutMapping, @DeleteMapping 가 있습니다.**
> 

**board/BoardController.java**

```java
@GetMapping("/")
public String index() {
    return "index";
}
```
