# 7. 게시글 삭제하기 리팩토링

이제 게시글과 관련된 기능에 대한 인증 및 권한 체크를 하겠습니다.

# 7.1 Exception403 만들기

> **403 에러(Forbidden)는 리소스에 접근할 권한이 없을 때 발생합니다.**
> 

core폴더 내부의 ex 폴더에 Exception403.java 파일을 생성합니다.

**springv1 > core > handler > ex**

**1.png**

Exception403 클래스의 내부는 다음과 같이 구현합니다.

**core/handler/ex/Exception403.java**

```java
package com.metacoding.springv1.core.handler.ex;

public class Exception403 extends RuntimeException {
    public Exception403(String msg) {
        super(msg);
    }
}
```

# 7.2 Controller 인증 체크

세션 정보를 활용해 로그인 여부를 체크해보겠습니다. 만약 삭제버튼을 클릭시 세션 정보가 없다면 401 에러를 반환합니다.

> **세션은 setAttribute를 통해 저장하고, getAttribute 를 통해 꺼내서 사용할 수 있습니다.**
> 

세션 정보가 있다면 게시글삭제 메서드에 세션 정보에 있는 ID 값을 전달합니다.

**BoardController.java**

```java
package com.metacoding.springv1.board;

import java.util.List;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.*;
import lombok.RequiredArgsConstructor;
import jakarta.servlet.http.*;
import com.metacoding.springv1.core.handler.ex.*;
import com.metacoding.springv1.user.User;

@RequiredArgsConstructor
@Controller
public class BoardController {

    private final BoardService boardService;
    private final HttpSession session; // 세션 추가

    @PostMapping("/boards/{id}/delete")
    public String deleteById(@PathVariable Integer id){
        User sessionUser = (User)session.getAttribute("session"); // 세션 꺼냄
        if(sessionUser == null){
            throw new Exception401("로그인이 필요합니다.");
        }
        boardService.게시글삭제(id,sessionUser.getId());
        return "redirect:/";
    }
		// 중략
}
```

로그인 하지 않고 삭제 버튼을 누르면 401 에러가 발생하며 RuntimeException 를 호출해 메세지를 전달합니다.

# 7.3 Service에서 권한 체크

컨트롤러에서 받은 세션의 사용자 ID와 작성자 ID를 비교합니다. 

먼저 게시글 ID로 작성자 ID를 조회한 뒤, 세션에 저장된 사용자 ID와 일치 여부를 검증합니다.

**BoardService.java**

```java
package com.metacoding.springv1.board;

import java.util.List;
import java.util.stream.Collectors;
import org.springframework.stereotype.Service;
import jakarta.transaction.Transactional;
import lombok.RequiredArgsConstructor;
import com.metacoding.springv1.core.handler.ex.*;
import com.metacoding.springv1.user.User;

@RequiredArgsConstructor
@Service
public class BoardService {

    private final BoardRepository boardRepository;
    
    @Transactional
    public void 게시글삭제(Integer boardId, Integer sessionUserId){
        Board board = boardRepository.findByIdJoinUser(boardId).orElseThrow(() -> new Exception404("게시글을 찾을 수 없습니다."));
        if(board.getUser().getId() != sessionUserId){
            throw new Exception403("게시글을 삭제할 권한이 없습니다.");
        }
        boardRepository.delete(board);
    }
        // 중략 
}

```

로그인 정보와 게시글의 작성자 정보가 일치하지 않으면 403 오류를 반환합니다.
