# 1.2 HTML 폼과 컨트롤러의 요청-응답 연결

이제 요청을 받을 컨트롤러를 구현하겠습니다.

springv1 디렉터리 안에 user 폴더를 생성합니다. 이 폴더는 사용자와 관련된 클래스들을 모아 관리하는 공간입니다.

user 폴더에 UserController.java 클래스를 생성합니다.

**src > main > java > com > metacoding > springv1 > user**

![**3.png**](1%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EC%B4%88%EA%B8%B0%20%ED%99%94%EB%A9%B4%20%EA%B5%AC%EC%84%B1%EA%B3%BC%20%EA%B5%AC%EC%A1%B0%20%EC%9D%B4%ED%95%B4/image%202.png)

**3.png**

회원가입폼 메서드를 구현합니다. /join-form 요청이 들어오면 join-form.mustache 뷰를 반환합니다.

**UserController.java**

```java
package com.metacoding.springv1.user;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.*;

@Controller
public class UserController {

    @GetMapping("/join-form")
    public String joinForm() {
        return "user/join-form";
    }
}
```

프로젝트 실행 후 헤더 부분의 회원가입 탭을 클릭하면 회원가입 페이지로 이동합니다.
