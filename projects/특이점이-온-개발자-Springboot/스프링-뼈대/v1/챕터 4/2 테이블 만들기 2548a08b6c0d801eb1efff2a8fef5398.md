# 2. 테이블 만들기

# 2.1 데이터베이스 테이블 관계 (1:N, N:N) 이해

> **관계형 데이터베이스는 데이터를 행(Row)과 열(Column) 구조의 테이블로 저장하고, 테이블 간의 관계를 통해 데이터를 관리하는 방식입니다. 테이블 간 관계의 종류에는 1:1 , 1:N , N:M 이 있습니다.**
> 

## 2.1.1 1:N관계

1대N 관계는 하나의 엔티티가 여러 개의 다른 엔티티와 연결되는 구조입니다.

고객 테이블과 제품 테이블이 존재한다고 가정합니다. 한 명의 고객(예: 고객 ID 1)은 여러 개의 제품을 구매할 수 있습니다. 반면, 제품은 재고 수량 개념이 없으므로 하나의 제품은 특정 고객 테이블의 단일 행과만 매핑됩니다.

**1.png**

따라서 전체 구조로 보면 **소비자(1) :** **제품(N)** , 즉 **1:N 관계**입니다.

관계형 데이터베이스에서 두 테이블 간의 연관 관계를 정의하고 연결하기 위해  외래 키(Foreign Key)를 정의해야 합니다.

User.java 클래스에 다음과 같이 작성합니다. 

user_tb 테이블과 매핑되는 User 엔티티 클래스입니다.

**User.java**

```java
package com.metacoding.springv1.user;

import java.sql.Timestamp;

import org.hibernate.annotations.CreationTimestamp;

import jakarta.persistence.*;
import lombok.*;

@NoArgsConstructor
@Data
@Entity  
@Table(name="user_tb") 
public class User {

    @Id
    @GeneratedValue (strategy = GenerationType.IDENTITY)  // 자동 증가
    private Integer id;
    @Column(unique = true)
    private String username;
    private String password;
    private String email;

    @CreationTimestamp // 자동으로 현재 시간 저장
    private Timestamp createdAt;

    // 객체 생성을 위한 생성자
    @Builder
    public User(Integer id, String username, String password, String email, Timestamp createdAt) {
        this.id = id;
        this.username = username;
        this.password = password;
        this.email = email;
        this.createdAt = createdAt;
    }
}
```

# 2.3 게시글(Board) 엔티티에 사용자 관계 설정

User 엔티티와 Board 엔티티의 관계를 맺어보겠습니다.

한 명의 사용자는 여러 게시글을 작성할 수 있으며, 각 게시글은 오직 한 명의 사용자에게만 속합니다.

따라서 회원(User) 엔티티와 게시글(Board) 엔티티는 **1:N 관계**를 이루며, 외래 키는 다수 쪽인 Board 엔티티에 두어야 합니다.

> **스프링 JPA에서는 단순히 키 값이 아니라 객체 자체를 참조할 수 있습니다.
@JoinColumn으로 지정한 user_id 컬럼을 기준으로 JPA가 자동으로 매핑을 처리하므로, Board 엔티티에서 곧바로 User 엔티티에 접근할 수 있습니다.**
> 

**Board.java**

```java
package com.metacoding.springv1.board;

import java.sql.Timestamp;

import org.hibernate.annotations.CreationTimestamp;

import com.metacoding.springv1.user.User;
import jakarta.persistence.*;
import lombok.*;

@NoArgsConstructor
@Data
@Entity  
@Table(name="board_tb") 
public class Board {
    @Id
    @GeneratedValue (strategy = GenerationType.IDENTITY)  // 자동 증가
    private Integer id;
    private String title;
    private String content;

    @CreationTimestamp // 자동으로 현재 시간 저장
    private Timestamp createdAt;

    @ManyToOne(fetch = FetchType.EAGER)  // 다대일 관계 설정
    @JoinColumn(name = "user_id") // 외래 키지정
    private User user; // 객체를 직접 참조

    @Builder // 빌더에 user 파라메터 추가하기
    public Board(Integer id, String title, String content, Timestamp createdAt, User user) {
        this.id = id;
        this.title = title;
        this.content = content;
        this.createdAt = createdAt;
        this.user = user;
    }
}
```

생성자는 User 객체를 매개변수로 받아, Board 엔티티 생성 시 User 정보를 함께 설정할 수 있도록 구성합니다.
