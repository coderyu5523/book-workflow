# 5. 사용자 인증: 로그인 및 세션 관리

# 5.1 Session 및 Request, Response

> **세션(Session)은 서버가 사용자의 인증 정보나 상태를 서버에 저장하고, 브라우저는 발급받은 세션 ID를 통해 이를 식별하는 방식입니다. 이를 통해 웹은 기본적으로 Stateless 구조임에도 불구하고 로그인 유지처럼 연속적인 상태 관리가 가능합니다.**
> 

클라이언트와 서버 간의 요청과 응답 과정을 헬스장 방문에 비유해 설명해보겠습니다.

## 5.1.3 쿠키(cookie)

> **쿠키(Cookie)는 웹 서버가 사용자의 브라우저에  저장하는 데이터입니다. 브라우저는 이후 요청 시 이 쿠키를 함께 전송하여 서버가 사용자를 식별하거나 인증할 수 있도록 합니다.**
> 

클라이언트가 서버에 요청 시, 서버는 HTTP의 Response header에 Set-Cookie를 함께 전송합니다.

**브라우저 F12 > Network > Header**

## 5.1.4 정리

클라이언트와 스프링 서버의 요청, 응답 과정을 정리하면 다음과 같습니다.

### **1. 클라이언트 요청**

• 클라이언트가 브라우저에서 **서버(헬스장)**에 접근하면, 서버는 요청을 **HttpServletRequest 객체(Request 가방)**에 담습니다.

### **2. 세션 생성 및 저장**

• 서버는 세션 생성 후, **세션ID(락커룸 번호)**를 만듭니다.

### **3. 서버 응답**

• 세션ID는 **JSESSIONID(락커룸 열쇠)**에 담습니다.

• 서버는 클라이언트에게 다시 보낼 데이터를 **HttpServletResponse 객체(Response 가방)**에 담아 전달합니다.

• 브라우저는 JSESSIONID을 쿠키에 저장합니다. 

### **4. 클라이언트 재요청**

• 클라이언트가 다시 요청을 보내면, 브라우저는 저장해둔 쿠키를 자동으로 Request 객체에 실어 전송합니다.
• 서버는 Request 에서 세션 ID를 꺼내 해당 사용자를 식별, 인증합니다.

# 5.3 UserService

UserService에 로그인 메서드를 작성합니다.

유저네임과 비밀번호를 검증한 뒤, 검증에 성공하면 해당 사용자의 User 엔티티를 반환합니다.

**UserService.java**

```java
package com.metacoding.springv1.user;

import org.springframework.stereotype.Service;
import com.metacoding.springv1.core.handler.ex.*;
import lombok.RequiredArgsConstructor;
import jakarta.transaction.Transactional;

@RequiredArgsConstructor
@Service
public class UserService {

    private final UserRepository userRepository;

    public User 로그인(UserRequest.LoginDTO requestDTO) {
        //  유저 조회
        User user = userRepository.findByUsername(requestDTO.getUsername())
                .orElseThrow(() -> new Exception404("유저네임을 찾을 수 없습니다.")); 
        // 비밀번호 확인
        if (!user.getPassword().equals(requestDTO.getPassword())) {
            throw new Exception401("비밀번호가 일치하지 않습니다.");
        }
        return user;
    }
    // 중략
}
```

# 5.4 UserController

> **로그인은 단순 조회가 아니라 인증이므로 GET 대신 POST로 처리합니다.
GET은 주소창(쿼리스트링)에 비밀번호가 남아 노출될 수 있지만, POST는 요청 본문으로 보내 위험을 줄일 수 있습니다.**
> 

다음과 같이 로그인 메서드를 작성합니다. userService를 통해 전달받은 user 엔티티를 세션에 저장합니다.

**UserController.java**

```java
package com.metacoding.springv1.user;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.*;
import lombok.RequiredArgsConstructor;
import jakarta.servlet.http.HttpSession;

@RequiredArgsConstructor
@Controller
public class UserController {

    private final UserService userService;
    private final HttpSession session; // 세션
    
    @PostMapping("/login")
    public String login(UserRequest.LoginDTO requestDTO){
        User user = userService.로그인(requestDTO);
        session.setAttribute("session", user); // 세션에 저장
        return "redirect:/";
    }
    // 중략
}
```

**application.properties**

```jsx

```

header.mustache 로 이동합니다.

> **Mustache 문법에서 {{#변수}} ... {{/변수}} 구문은 해당 변수가 참이거나 값이 존재할 때 내부 내용을 렌더링합니다. 반대로 {{^변수}} ... {{/변수}} 구문은 변수가 거짓이거나 값이 없을 때 내부 내용을 렌더링합니다.**
> 

Mustache 문법을 활용하여, 세션이 존재할 경우에는 글쓰기와 로그아웃 버튼을, 세션이 없을 경우에는 회원가입과 로그인 버튼을 표시하도록 구현합니다.

**header.mustache**

```jsx
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</head>
<body>

<nav class="navbar navbar-expand-sm" style="background-color: grey;">
  <div class="container-fluid">
    <ul class="navbar-nav">
       <li class="nav-item">
        <a class="nav-link" href="/" style="font-weight: bold; color: white">Metacoding</a>
      </li>
    {{#session}}
      <li class="nav-item">
        <a class="nav-link" href="/boards/save-form" style="color: white">글쓰기</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="/logout" style="color: white">로그아웃</a>
      </li>
    {{/session}}
    {{^session}}
      <li class="nav-item">
        <a class="nav-link" href="/join-form" style="color: white">회원가입</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="/login-form" style="color: white">로그인</a>
      </li>
    {{/session}}

    </ul>
  </div>
</nav>
</div>
```

# 5.6 로그아웃

로그아웃은 현재 세션을 종료하여 사용자 정보를 초기화하는 방식으로 처리합니다.

**UserController.java**

```jsx
@GetMapping("/logout")

    session.invalidate(); // 세션 종료
    return "redirect:/";
}
```
