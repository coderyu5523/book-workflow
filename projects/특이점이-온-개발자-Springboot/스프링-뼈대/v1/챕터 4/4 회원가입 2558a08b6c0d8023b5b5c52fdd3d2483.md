# 4.1 requestDTO

먼저 사용자가 입력한 데이터를 전달받기 위한 DTO 클래스를 생성하겠습니다.
user 폴더에 UserRequest.java 파일을 추가합니다.

**src > main > java > com > metacoding > springv1 > user**

![**1.png**](4%20%ED%9A%8C%EC%9B%90%EA%B0%80%EC%9E%85/image.png)

**1.png**

아래와 같이 SaveDTO를 내부 클래스로 정의하고, 그 안에 User 엔티티를 생성하는 메서드를 구현합니다.

또한 DTO의 필드명은 join-form.mustache 의 <input> 태그에서 지정한 name 속성과 동일해야 자동으로 매핑됩니다.

**UserRequest.java**

```java
package com.metacoding.springv1.user;

import lombok.Data;

public class UserRequest {

    @Data
    public static class SaveDTO{
        private String username;
        private String password;
        private String email;
        
        // 객체 생성
        public User toEntity(){
            return User.builder()
            .username(username)
            .password(password)
            .email(email)
            .build();
        }
    }
}
```

# 4.2 Exception401 만들기

이번 챕터에서는 예외 처리를 해보겠습니다.

> **예외 처리(Exception Handling)는 프로그램 실행 중 발생할 수 있는 예외 상황을 안전하게 처리하고, 프로그램이 중단되지 않도록 하는 장치입니다.**
> 

springv1 패키지 안에 core 폴더를 생성하고, 아래 구조에 맞게 Exception401.java 클래스를 작성합니다.

**springv1 > core > handler > ex**

![**2.png**](4%20%ED%9A%8C%EC%9B%90%EA%B0%80%EC%9E%85/image%201.png)

**2.png**

> **401 오류(Unauthorized)는 인증 실패 시 발생하며, 사용자가 로그인하지 않은 상태에서 보호된 자원에 접근하려 할 때 주로 나타납니다.**
> 

아래와 같이 Exception401 클래스를 구현합니다.
이 클래스가 호출되면 전달받은 메시지를 부모 클래스인 RuntimeException에 넘겨 처리합니다.

 **core/handler/ex/Exception401.java**

```
package com.metacoding.springv1.core.handler.ex;

public class Exception401 extends RuntimeException {
    public Exception401(String msg) {
        super(msg);
    }
}
```

userService에 회원가입 메서드를 구현합니다.
사용자가 입력한 사용자명을 기준으로 중복 여부를 확인하고, 중복되지 않는 경우에만 저장합니다.

**UserService.java**

```java
package com.metacoding.springv1.user;

import org.springframework.stereotype.Service;
import com.metacoding.springv1.core.handler.ex.*;
import lombok.RequiredArgsConstructor;
import jakarta.transaction.Transactional;

@RequiredArgsConstructor
@Service
public class UserService {

    private final UserRepository userRepository;

    @Transactional
    public void 회원가입(UserRequest.SaveDTO requestDTO){
        // 중복 체크
        if (userRepository.findByUsername(requestDTO.getUsername()).isPresent())
            throw new Exception401("이미 존재하는 유저네임입니다.");
        // 회원가입
        User user = requestDTO.toEntity();
        userRepository.save(user);
    }
}
```

UserController에 join 메서드를 구현합니다.
이 메서드는 DTO를 매개변수로 받아 userService의 회원가입 메서드를 호출하고, 회원가입이 완료되면 로그인 페이지로 리다이렉트합니다.

**UserController.java**

```java
package com.metacoding.springv1.user;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.*;
import lombok.RequiredArgsConstructor;

@RequiredArgsConstructor
@Controller
public class UserController {

    private final UserService userService;
    
    @PostMapping("/join")
    public String join(UserRequest.SaveDTO requestDTO){
        userService.회원가입(requestDTO);
        return "redirect:/login-form";
    }   
    // 중략
}
```
