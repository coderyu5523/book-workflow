# 6.1 EAGER

> **EAGER는 엔티티를 조회할 때 연관 엔티티를 즉시 함께 로딩하는 전략으로, 보통 조인 한 번에 묶어서 가져옵니다.**
>

@ManyToOne 의 기본 페치 전략은 EAGER이지만, 의도를 명확히 하기 위해 표기하였습니다.

> 

@ManyToOne의 속성을 LAZY로 적용합니다.

# 6.4 findByIdJoinUser()

이번에는 JOIN 문을 사용해 두 엔티티를 조회하도록 하겠습니다.

JPQL의 JOIN 문법은 다음과 같습니다.

JPQL의 JOIN은 연관관계 필드를 통해서만 사용합니다. 

**기본 JOIN**

```sql
select b from Board b join b.user u where u.username = :username
```

일치 값이 없어도 기준 테이블을 조회하고 싶다면 LEFT/RIGHT OUTER JOIN을 사용합니다.

**LEFT OUTER JOIN**

```sql
select b, u from Board b left join b.user u where u.username = :username
```

> **일반 JOIN은 LazyLoading을 사용합니다. 조회 시 연관된 엔티티를 한 번에 가져오고 싶다면 FETCH JOIN을 사용해야 합니다.**
> 

**FETCH JOIN**

```sql
select b from Board b left join fetch b.user where b.id = :id
```

FETCH JOIN을 활용해 findByIdJoinUser 메서드를 구현합니다.

**BoardRepository.java**

```jsx
public Optional<Board> findByIdJoinUser(int id){
    Optional<Board> board = em.createQuery("select b from Board b join fetch b.user where b.id = :id", Board.class)
                        .setParameter("id", id)
                        .getResultStream()
                        .findFirst();
    return board;
}
```

<aside>
💡

**연관 데이터는 기본 속성을 LAZY로 두어 실제 접근 시에만 로딩합니다. 다만 화면별 시나리오에 따라 LazyLoading이 불필요한 추가 조회를 유발할 수 있으므로, 필요한 경우에만 FETCH JOIN으로 로딩해 쿼리 수와 전송량을 최소화해야 합니다.**

</aside>

# 6.6 Service

이제 게시글 상세보기 페이지에 User 엔티티도 함께 바인딩하겠습니다.

BoardService의 게시글상세 메서드에서 기존 findById메서드를 주석 처리하고, findByIdJoinUser 메서드를 호출합니다.

**BoardService.java**

```java
public BoardResponse.DetailDTO 게시글상세(Integer id) {
    //Board board = boardRepository.findById(id).get(); // pk 로 조회
    Board board = boardRepository.findByIdJoinUser(id).orElseThrow(() -> new Exception404("게시글을 찾을 수 없습니다."));
    BoardResponse.DetailDTO dto = new BoardResponse.DetailDTO(board); // DTO 담기기
    return dto;
}
```

만약 게시글이 없다면 404 에러 예외처리를 합니다.

# 6.7 BoardResponse

BoardResponse 의 DetailDTO 클래스에 userId와 username 필드를 추가합니다.

**BoardResponse.java**

```java
package com.metacoding.springv1.board;

import lombok.Data;

public class BoardResponse {

    @Data
    public static class DetailDTO {

        private Integer id;
        private String title;
        private String content;
        private Integer userId;
        private String username;

        public DetailDTO (Board board) {
            this.id = board.getId();
            this.title = board.getTitle();
            this.content = board.getContent();
            this.userId = board.getUser().getId();
            this.username = board.getUser().getUsername();
        }
    }
    // DTO 중략   
}
```

이제 BoardService에서 Board 엔티티를 DetailDTO 에 담으면 userId와  username 까지 함께 반환됩니다.
