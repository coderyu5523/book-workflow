# 9. 게시글 수정 화면 리팩토링

게시글 수정 화면에 대한 인증, 권한을 체크하겠습니다.

# 9.1 게시글 수정 화면 Controller 인증 체크

세션에 저장된 사용자 정보를 확인해 로그인 상태를 검증합니다.

**BoardController.java**

```java
@GetMapping("/boards/{id}/update-form")
public String updateForm(HttpServletRequest request, @PathVariable("id") Integer id) {
    User sessionUser = (User)session.getAttribute("session");
    if(sessionUser == null){
        throw new Exception401("로그인이 필요합니다.");
    }
    BoardResponse.DTO board = boardService.게시글수정폼(id,sessionUser.getId());
    request.setAttribute("model", board);
    return "board/update-form";
}
```

# 9.2 게시글 수정 화면 Service 권한 체크

게시글 수정 페이지로 이동 시 세션의 사용자 정보와 게시글의 작성자 정보를 체크합니다.

**BoardService.java**

```java
public BoardResponse.DTO 게시글수정폼(Integer boardId, Integer sessionUserId){
    Board board = boardRepository.findByIdJoinUser(boardId).orElseThrow(() -> new Exception404("게시글을 찾을 수 없습니다."));
    if(board.getUser().getId() != sessionUserId){
        throw new Exception403("게시글을 수정할 권한이 없습니다.");
    }
    BoardResponse.DTO dto = new BoardResponse.DTO(board);
    return dto;
}
```

사용자 정보와 게시글의 작성자 정보가 일치하지 않으면 403 에러가 발생합니다.
