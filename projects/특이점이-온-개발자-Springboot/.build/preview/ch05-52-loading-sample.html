5.2 즉시 로딩과 지연 로딩

JPA로 개발할 때 마주하는 가장 흔한 성능 문제는 당장 필요 없는 연관 데이터까지 조회하는 상황입니다. 게시글 목록 화면을 예로 들어 보겠습니다. 목록에는 회원 정보가 보이지 않습니다. 그런데 findAll()로 전체 목록을 조회할 때 JPA가 연관된 회원 엔티티까지 함께 가져온다면, 게시글마다 회원을 조회하는 쿼리가 따로 실행됩니다. 화면에 쓰지도 않는 데이터 때문에 데이터베이스와 서버의 부담이 커집니다.

이러한 성능 저하를 막기 위해 JPA는 연관된 데이터를 조회하는 시점에 한 번에 가져올지, 아니면 실제로 사용하는 시점에 조회할지를 개발자가 직접 정할 수 있도록 두 가지 로딩 방식을 제공합니다.

5.2.1 즉시 로딩

즉시 로딩(Eager Loading) 은 엔티티를 조회할 때 연관된 엔티티까지 한 번에 가져오는 방식입니다. 게시글을 읽는 순간 JPA가 작성자까지 조회해 Board의 user 필드에 담아 둡니다.

@ManyToOne은 기본 전략이 즉시 로딩입니다. 앞서 Board에 작성자를 연결할 때는 fetch 속성을 지정하지 않았으므로, 작성자 필드가 이 방식으로 동작했습니다.

그래서 findAll()로 게시글 목록을 조회하면 JPA가 board_tb를 읽은 뒤, 작성자를 채우려고 user_tb를 조회하는 쿼리를 따로 실행합니다.

실행결과
Hibernate:
    select b1_0.id, b1_0.content, b1_0.created_at, b1_0.title, b1_0.user_id
    from board_tb b1_0
Hibernate:
    select u1_0.id, u1_0.created_at, u1_0.email, u1_0.password, u1_0.username
    from user_tb u1_0
    where u1_0.id=?
그림 5-4. 즉시 로딩으로 목록을 조회할 때의 쿼리

화면에 보이지도 않는 회원을 게시글마다 조회합니다. 이럴 때는 반대 방식인 지연 로딩을 선택합니다.

5.2.2 지연 로딩

지연 로딩(Lazy Loading) 은 엔티티를 먼저 조회하고, 연관된 엔티티는 실제로 접근하는 순간에 조회하는 방식입니다. 게시글을 조회할 때 JPA는 게시글 데이터만 읽고, 작성자는 그 값을 꺼내 쓰는 시점에 조회합니다.

작성자를 지연 로딩으로 바꾸려면 앞서 적은 것처럼 fetch 속성에 FetchType.LAZY를 지정합니다.

board/Board.java. 작성자 조회를 지연 로딩으로    @ManyToOne(fetch = FetchType.LAZY)
    private User user;

작성자 필드가 LAZY이므로 findAll()로 목록을 조회할 때는 user_tb 쿼리가 실행되지 않습니다. 목록이 작성자를 꺼내 쓰지 않기 때문입니다.

작성자를 꺼내 쓰는 조회에서는 그 시점에 쿼리가 나갑니다. findById()로 게시글을 조회한 뒤 getUsername()으로 작성자 이름에 접근하면, 그 순간 user_tb를 조회하는 쿼리가 실행됩니다.

실행결과
Hibernate:
    select b1_0.id, b1_0.content, b1_0.created_at, b1_0.title, b1_0.user_id
    from board_tb b1_0
    where b1_0.id=?
Hibernate:
    select u1_0.id, u1_0.created_at, u1_0.email, u1_0.password, u1_0.username
    from user_tb u1_0
    where u1_0.id=?
그림 5-5. 지연 로딩으로 조회할 때의 쿼리
실무에서는 어떤 로딩 방식을 쓰는가

연관된 데이터를 가져오느라 추가 쿼리가 계속 늘어나는 상황을 막기 위해, 실무에서는 모든 연관관계를 지연 로딩으로 설정합니다. 두 엔티티를 항상 함께 사용하는 경우에만 즉시 로딩을 고려하되, 지연 로딩을 유지한 채 필요한 조회에서만 쿼리로 묶어 한 번에 가져오는 편이 안전합니다. @ManyToOne은 기본값이 즉시 로딩이라 fetch = FetchType.LAZY를 직접 적어야 하고, @OneToMany는 기본값이 지연 로딩입니다.
