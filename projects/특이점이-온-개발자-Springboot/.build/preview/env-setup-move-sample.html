1. 소스코드 준비 (챕터 1 바로 앞)
변경 전

소스코드 준비

이 책의 실습 코드는 두 레포로 제공됩니다. 시작하기 전에 start 레포를 한 번만 클론해 두면, 챕터마다 해당 폴더로 이동해 바로 실습할 수 있습니다.

터미널 예제 레포 클론
git clone https://github.com/metacoding-06-springboot-v1/start.git
레포 용도 주소
start 직접 작성하는 예제(실습용). 클론해서 진행 https://github.com/metacoding-06-springboot-v1/start
final 완성된 전체 코드. 막히면 참고 https://github.com/metacoding-06-springboot-v1/final

두 레포 모두 챕터별 폴더로 나뉘어 있습니다.

챕터 폴더 주제
챕터 1 ch01 리플렉션과 컴포넌트 스캔 (순수 자바)
챕터 2 ch02 게시판 CRUD와 JPA
챕터 3 ch03 예외 처리와 DTO
챕터 4 ch04 인증과 인가
챕터 5 ch05 댓글과 JPA 심화

start 레포의 각 폴더는 핵심 로직 자리가 비어 있습니다. 챕터를 따라 코드를 채우고, 막히면 final 레포의 같은 폴더에서 완성 코드를 확인하세요.

챕터 1은 스프링 프로젝트가 아니라 순수 자바입니다. 빌드 도구 없이 IDE에서 각 App.java의 main 메서드를 실행합니다. 챕터 2부터는 스프링 부트 프로젝트이고, 실행과 데이터베이스 설정은 챕터 2에서 함께 다룹니다.

개발 환경

이 책은 VS Code에서 실습합니다. 상단 탭에서 View > Extensions를 선택합니다.

검색창에 java를 넣어 Extension Pack for Java를 설치합니다. 설치가 끝나면 챕터 1의 App.java를 열어 main 메서드를 바로 실행할 수 있습니다.

2. 챕터 2 · 2.2.1 프로젝트 생성
변경 전

2.2.1 프로젝트 생성

이 책의 실습 방식

본격적인 실습은 미리 준비해 둔 start 레포에서 진행합니다. 다만 첫 프로젝트 생성 과정은 직접 눈으로 확인해 보는 것이 좋으므로 여기서는 프로젝트를 만드는 절차만 먼저 살펴보겠습니다.

먼저 자바와 스프링을 다룰 확장 프로그램을 설치합니다. 상단 탭에서 View > Extensions를 선택합니다.

그림 2-7. Extensions 메뉴 선택

검색창에 java를 넣어 Extension Pack for Java를 설치합니다.

그림 2-8. Extension Pack for Java

이어서 spring으로 검색해 Spring Boot Extension Pack을 설치합니다. 이 확장에 스프링 프로젝트를 만들어 주는 Spring Initializr가 들어 있습니다.

그림 2-9. Spring Boot Extension Pack

설치가 끝나면 View > Command Palette를 엽니다.

그림 2-10. Command Palette 선택

spring을 입력해 Spring Initializr: Create a Gradle Project를 실행합니다.
