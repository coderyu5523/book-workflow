CH01 개념도 — 사물 일러스트 초안 (도커·MSA 스타일)

라벨 붙은 네모 대신, 실제 사물을 그린 일러스트. 네 개 모두 초안입니다.

그림 1-2 프레임워크 — 책장(라이브러리) vs 건축 중인 집(프레임워크)

라이브러리는 책장에서 필요한 책을 뽑아 쓰고, 프레임워크는 이미 선 골조 안에 내 방만 채웁니다

그림 1-3 제어의 역전 — 리모컨(주도권)이 넘어간다

라이브러리는 개발자가 리모컨을 쥐지만, 프레임워크에서는 프레임워크가 리모컨을 쥐고 내 코드를 호출합니다

그림 1-7 빈(Bean)·DI — 스프링 창고에서 꺼내 끼워 준다

스프링이 표식 붙은 클래스를 객체(빈)로 만들어 창고에 두고, 필요한 객체에 꺼내 끼워 줍니다

그림 1-1 챕터 실습 흐름 — 직접 배선 → 표식 → 자동 스캔

직접 배선(if-else)에서 표식(리플렉션)으로, 다시 자동 스캔으로 갈수록 스프링이 더 많이 대신합니다
