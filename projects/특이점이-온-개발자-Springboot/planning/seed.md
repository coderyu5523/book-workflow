# 씨앗

## 주제

원리와 실전을 잇는 스프링 부트 개념서. 순수 자바 리플렉션으로 "스프링의 마법"을 직접 만들어 벗겨낸 뒤, 그 이해 위에서 게시판을 만들며 스프링의 전체 개념과 핵심 이론을 잡는다. 코드는 핵심만 싣고 전체는 GitHub 참고 (MSA·도커 책과 같은 방향).

## 저자 이름 / 브랜드명

오픈스킬북스 — 프롤로그 주인공은 "오픈이" (MSA·도커 책과 같은 계보). 저자 개인 이력은 STEP 7 머릿말에서 확정.

## 집필 동기

스프링 부트의 전체적인 개념을 알려주고 싶다. 어노테이션을 그냥 외워 쓰는 게 아니라, "왜 그렇게 도는지"를 이해한 채로 쓰게 만든다.

## 저자 경험

책의 축으로 삼지 않는다. 주인공 오픈이를 "스프링을 처음 공부하는 전형적 학생 개발자"로 범용 설정한다.

## 핵심 메시지

(보류 — 집필하며 프롤로그·에필로그와 함께 확정)
후보: "원리를 알면 스프링은 마법이 아니라 내 손으로 만들 수 있는 규칙이 된다."

## 책의 의도

독자가 스프링의 동작 원리와 전체 개념을 **이해**하고, 게시판을 직접 따라 만들 수 있게 한다. 이해가 8, 구축이 2. 코드는 핵심만, 나머지는 GitHub. 이 필터로 이후 모든 결정을 거른다.

## 의도 밖 범위

완성 코드에 있어도 다루지 않는다.

- BCrypt 내부 알고리즘 (쓰는 것까지만)
- Gradle 빌드 설정 상세 (의존성 추가 수준)
- H2 외 실제 DB(MySQL 등) 전환 (로컬 H2로만)
- 프론트엔드·화면 (JSP·타임리프) — API·백엔드에 집중
- 배포·운영 (도커·클라우드) — 로컬 실행까지만

## 의도 안, 제대로 다루는 것

- **리플렉션** (ch01): `@RequestMapping`·`@Controller`를 직접 만들고 리플렉션으로 호출·스캔 → 스프링 내부 원리 구현
- **JPA 동작 원리**: 영속성 컨텍스트·더티체킹 등 원리까지
- **단위 테스트·통합 테스트 개념** (JUnit)
- **JWT 구조** (간단히) + 발급·검증 흐름, 필터·인터셉터 인증

## 차별점

어노테이션을 외우게만 시키는 스프링 책과 다르다. 리플렉션으로 "마법의 정체"를 손으로 구현해보고 JPA 동작까지 파고들어, 프레임워크를 블랙박스가 아니라 이해한 채로 쓰게 만든다.

## 프롤로그 트리거

고통·좌절에서 출발하지 않는다. 주인공 오픈이가 학생으로서 "무언가를 만들고 싶어서" 스프링을 공부하기 시작하는 능동적 학습 동기에서 문을 연다.

## 기술 스택 (코드 스캔)

Spring Boot 4.0.3, Java 21, Gradle / Spring Web·Data JPA·Validation·H2 / java-jwt(auth0)·BCrypt·Lombok·JUnit

## 코드 구조 (챕터 축)

- **ch01** `com.reflection` — 리플렉션 3단계 (ex01 하드코딩 분기 → ex02 `@RequestMapping`+invoke → ex03 `@Controller` 스캔+클래스로더)
- **ch02** `springv3` board + core/util — 게시판 CRUD (JPA, H2)
- **ch03** + core/handler — 전역 예외 처리
- **ch04** + config·filter·interceptor·user — JWT 인증
- **ch05** + reply — 댓글
