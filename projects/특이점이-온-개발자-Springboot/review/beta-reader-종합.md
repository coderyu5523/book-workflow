## 전 챕터 반복 이슈 (교차 — 일괄 수정 대상)
1. **패키지명 불일치** — 본문 `com.metacoding.spring` vs 실제 코드 `com.metacoding.springv3`. CH02~CH05 거의 전원 지적. **최우선 일괄 수정**(모든 prep 박스).
2. **show-sql 켜라 하고 실제 SQL 로그 실물 미노출** — CH02(캐싱·쓰기지연·더티체킹), CH05(N+1 vs fetch join). JPA 책의 핵심 증거인데 그림/산문만.
3. **"변경" 파일이 코드블록 없이 산문만** → 구축 독자가 완성본 열어 유추 — CH04 BoardController, CH05 WebMvcConfig, CH03 Board @Builder.
4. **실습 순서 함정**(참조가 정의보다 앞) — CH02 SaveDTO, CH03 Exception404, CH04 Exception401/403.
5. **요청 전송 도구(Postman/curl) 안내 부재** — 실무0 독자가 첫 실습에서 멈춤(CH02~CH05).
6. **`[CAPTURE NEEDED]` 미충족** — 결과 확인 화면 공백(출간 전 예정 작업).

## 챕터별 최우선 수정 (심각~높음)
- **CH01**: 실습5·8·findUri의 checked 예외(`invoke`/`Class.forName`/`newInstance`/`toURI`)에 throws/try-catch 없어 그대로 치면 컴파일 실패(전원). 1.7 용어·풀링/DBCP 과부하.
- **CH02**: `@GeneratedValue(IDENTITY)`라 persist 시 즉시 INSERT → 그림 2-6 쓰기지연 설명과 충돌(show-sql 켜면 로그가 반대). `./gradlew test`로 eye용 println 안 보임.
- **CH03**: 3.3 "나머지 메서드도 같은 식으로"가 목록 `stream().map()` 코드 안 보여줌(초보 블로커). Board `@Builder` 파일트리 누락.
- **CH04**: 회원가입 중복에 `Exception401`(정의↔사용 충돌, 7명). BoardController 코드 공백. ER 다이어그램·로그인 시드 평문 부재(재현 불가). Spring Security 미언급.
- **CH05**: **잔존 N+1** — 상세 조회 시 `reply.getUser()`가 댓글마다 lazy select → "쿼리 하나로 끝난다"가 코드상 거짓(실습7이 우연히 회피). EAGER/LAZY 수동 토글. 컬렉션 fetch join 함정(중복 행/페이징 불가) 미언급.
