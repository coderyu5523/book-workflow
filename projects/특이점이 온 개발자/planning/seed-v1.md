# 씨앗

## 주제
Docker & Kubernetes 컨테이너 인프라 — 도커 기초 명령어, 프로비저닝, 쿠버네티스 리소스 활용, 네트워크 및 동작 방식을 큰 그림으로 잡는 개념서.

## 집필 동기
수업 교재. 처음에 도커/쿠버네티스의 네트워크와 동작 원리를 큰 그림으로 이해시키고, 그 다음 예제 실습으로 큰 그림을 다시 체험하는 2단 구조. 일반적인 IT 책의 명령어 나열이 아니라 스토리텔링으로 독자가 자연스럽게 따라올 수 있게 만든다.

## 책의 의도
독자가 이 책을 덮었을 때 갖고 가는 것.

- 도커 & 리눅스 & 쿠버네티스 명령어 실습
- 컨테이너가 왜 필요한지 — 가상머신과 뭐가 다르고, 왜 이쪽으로 옮겨가는지
- 도커 네트워크 동작 원리 — 브릿지, 포트포워딩, 컨테이너 간 DNS
- Dockerfile과 이미지 빌드 — 작성법과 빌드 흐름 (레이어 구조 같은 내부 심화는 제외)
- 볼륨과 영속 데이터 — 컨테이너가 죽어도 데이터가 살아남는 구조
- Docker Compose — 여러 컨테이너를 선언형으로 한 번에 올리는 방법
- K8s 리소스 전체 그림 — Pod, Deployment, Service, ConfigMap, Secret, PV/PVC, Ingress가 각각 뭐고 어떻게 물려 있는지
- 도커 → K8s 전환 경험 — 같은 앱을 Compose에서 K8s로 옮기는 과정

전부 다루되 깊지 않게. "아, 이게 이거구나"를 잡아주는 큰 그림 수준.

## 의도 밖 범위
완성 코드에 있어도 다루지 않는 것들.

- 리눅스 명령어 심화
- Flask/Python 앱 코드 상세 (app.py 로직 설명)
- Spring Boot/Java 앱 코드 상세 (백엔드 코드 설명)
- Nginx 설정 심화 (캐싱 전략, 프록시 최적화)
- MySQL 운영/쿼리 최적화
- Redis 운영/데이터 구조 심화
- K8s 클러스터 구축/운영 (kubeadm, 노드 관리 — Minikube 넘어서는 영역)
- CI/CD 파이프라인
- 모니터링/로깅 (Prometheus, Grafana 등)

앱 코드는 "이미 있다고 치고" 컨테이너화에만 집중한다.

## 차별점
- **"특이점이 온 개발자" 시리즈** 중 Docker&K8s 편
- **AI가 작성한 책** — 스토리텔링 형식으로 독자가 이해하기 쉽게 구성
- **큰 그림 먼저 → 실습으로 재확인** — 동작 원리를 이야기로 먼저 풀고, 같은 내용을 예제로 다시 체험
- **같은 앱의 성장** — 하나의 앱이 도커 단독 → Compose → K8s로 올라가는 과정을 따라가며 "왜 이게 필요한지"를 자연스럽게 체감
- **단계별 학습** - 1. 도커&리눅스 명령어를 통해 리눅스의 기본기 2. Dockerfile, docker-compose를 통한 프로비저닝 3. 쿠버네티스 순으로 단계별 학습

## 핵심 메시지
"컨테이너는 앱을 담는 상자다. 상자 하나를 만들고, 여러 개를 엮고, 수백 개를 관리하는 법까지 — 하나의 앱이 성장하는 과정을 따라가면 Docker와 Kubernetes의 큰 그림이 잡힌다."
