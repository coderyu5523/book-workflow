# 도커-쿠버네티스 책 개요 챕터 추가 + 번호 재정렬

## 배경

MSA 책 CH01처럼 "숲을 먼저 보여주는" 개요 챕터가 도커-쿠버네티스 책에 없다.
기존 CH01이 바로 Docker 개념 + 실습으로 진입하여, 독자가 전체 여정을 파악하기 어렵다.

## 목표

1. 새 CH01 개요 챕터 생성 (문제 제기 + Docker/K8s 개념 + 로드맵)
2. 기존 CH01~03을 CH02~04로 번호 재정렬
3. 기존 파일 보존, 모든 변경은 새 버전 파일로 생성

## 설계

### 새 CH01: 왜 컨테이너인가

기존 CH01의 1.1(말콤 맥린)과 1.2(Docker 작동 원리)를 이동하고,
K8s 개요(1.3)와 로드맵(1.4)을 신규 작성한다.

```
# 챕터 1. 왜 컨테이너인가

## 학습 목표

## 1.1 말콤 맥린 : 컨테이너의 아버지
  ### 1.1.1 해상 운송의 초기
  ### 1.1.2 컨테이너의 도입
  ### 1.1.3 IT에서의 컨테이너
  → 기존 CH01 1.1 그대로 이동 (이미지 참조 포함)

## 1.2 Docker : 컨테이너를 쉽게 쓰는 도구
  ### 1.2.1 가상화 : 하나의 컴퓨터를 여러 개로 사용하는 법
  ### 1.2.2 컨테이너 가상화 : OS 없이 격리하다
  ### 1.2.3 Docker : 이미지에서 컨테이너까지
  → 기존 CH01 1.2 그대로 이동 (이미지 참조 포함)

## 1.3 Kubernetes : 컨테이너가 많아지면    ← 신규
  - 컨테이너 수십 개 수동 관리의 문제
  - 오케스트레이션 개념 (자동 복구, 스케일링, 무중단 배포)
  - Docker Compose vs Kubernetes 포지션 차이
  - 비유 중심, 코드 없음

## 1.4 이 책에서 만드는 것    ← 신규
  - 챕터 2: Docker 기본 (설치, CLI, 리눅스, 이미지 만들기)
  - 챕터 3: Docker 심화 (Dockerfile, Nginx, Redis, MySQL, Compose, 풀스택)
  - 챕터 4: Kubernetes (Minikube, Pod, Deployment, Service, 풀스택 K8s 배포)
  - 아키텍처 그림 + 챕터별 한 줄 요약
```
