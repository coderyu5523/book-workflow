# 종이책 표지 시안 (46배판 188x254mm, 날개 없음)

스프링 부트 책(`projects/특이점이-온-개발자-Springboot`)의 종이책 표지를 정하려고 만든 시안 모음입니다. 최종 표지 생성기(`../generate_openskill_paper_covers.py`)는 아직 이 시안의 디자인을 반영하지 않았고, 회색/검정 초안을 그립니다. 방향이 정해지면 `draw_back`·`draw_spine`에 이식합니다.

## 파일

| 파일 | 내용 |
|------|------|
| `back_options.py` | 뒷표지 시안. `option3()`(글 최소), `option3b()`(소개 문단 + 항목별 한 줄 설명 + 난이도·QR·바코드·정가). `option3b`는 색 인자로 바탕·포인트·제목·카드 색을 바꾼다 |
| `spread_options.py` | 앞표지 변형 + 뒷표지 + 책등을 붙인 펼침면 시안. 실행하면 `spread-G1.png`, `spread-G2.png`, `front-options.png`를 만든다 |
| `back-options.png` | 뒷표지 시안 3 이전/보강 비교(주황+피치 색) |
| `front-options.png` | 흰 바탕 + 스프링 초록 한 색 안. 책등 A(흰색)와 B(초록)를 나란히 비교 |
| `spread-G1.png`, `spread-G2.png` | 같은 안의 전체 펼침면(4616x3070px, 300dpi). G1 = 흰 책등 + 검정 글씨, G2 = 초록 책등 + 흰 글씨 |
| `earlier/spread-A·B·C.png` | 이전 앞표지 후보. A = 흰 바탕 + 짙은 갈색 Spring + 주황 Boot, B = 흰 바탕 + 주황 Spring, C = 피치 바탕 |
| `earlier/spread-D1~D4.png` | 피치 바탕 + 검정 Boot에 책등 색 4종을 얹어 본 것 |

## 다시 만들기

```bash
PYTHONUTF8=1 python docs/images/covers/paper-cover-samples/back_options.py
PYTHONUTF8=1 python docs/images/covers/paper-cover-samples/spread_options.py
```

- 이 폴더의 스크립트는 같은 폴더에 결과를 덮어쓴다(이름이 같은 파일을 갱신)
- 책등 두께는 9.0mm(180쪽 x 0.1mm 추정)로 고정했다. 인쇄소가 알려 준 값으로 `spread_options.py` 위쪽의 `pc.set_geometry(9.0)`를 바꾼다
- `spread_options.py`의 `spread(variant, spine, back_kwargs)`에 `render_front`의 variant(A, B, C, D, G)와 책등 색을 주면 다른 조합도 만든다

## 시안에서 정한 것과 이유

- 앞표지는 흰 바탕에 스프링 초록 한 색만 쓴다. `Spring`은 초록, `Boot`·시리즈명·부제는 검정
- 뒷표지는 흰 바탕, 2줄 헤드라인(앞줄 검정, 뒷줄 초록), 소개 두 문장, 초록 체크 아이콘이 붙은 항목 5줄(연초록 카드), 하단에 난이도·QR(실습 코드)·바코드·정가
- 근거는 국내 IT 입문서 20권의 앞뒤 표지를 비교한 결과다. 표본은 알라딘 미리보기를 제공하는 책이고, 색 계열은 채도가 높은 색이 화면의 4% 이상일 때만 셌다
  - 앞표지 배경은 흰색 17권, 우주 사진 1권, 진한 보라 1권, 회색 블록 1권이고, 연한 색으로 전면을 채운 표지는 없었다
  - 색 계열은 1계열 12권, 2계열 3권, 거의 무채색 5권이었고 3계열 이상은 없었다
  - 앞뒤 표지의 색 계열은 비교할 수 있는 5권 모두 같았다
  - 색은 기술 이름, 로고, 일러스트에 쓰고, 기술의 대표색을 따른다(스프링 책 4권 중 3권이 초록, 도커·쿠버네티스는 대부분 파랑)
  - 뒷표지는 내용을 항상 덩어리(목록·카드)로 나누고, 하단 12~15%를 바코드 등 메타 영역으로 쓴다
- 참고한 책 표지 이미지는 저작권 때문에 저장소에 넣지 않았다. 책등은 알라딘에 이미지가 없어서 확인하지 못했다

## 아직 정해지지 않은 것

- 책등 색: A(흰색) 또는 B(초록). 초록 책등은 색 계열이 하나로 유지되고 서가에서 눈에 띄지만, 실제 책등의 관례는 확인하지 못했다
- 책등 두께: 인쇄소가 알려 주는 값
- 뒷표지 문구: 저자 확인 전 초안이다. `book/출판등록-책소개.txt`가 생기면 그 문구를 우선한다
- QR 주소: 현재 `https://github.com/metacoding-06-springboot-v1/start`(1장 원고의 주소)
- 인쇄 서비스가 ISBN 바코드를 자동으로 넣는지, 부가기호(5자리)가 필요한지
- 연한 색(연초록 카드)이 CMYK 인쇄에서 어떻게 나오는지: 시안 인쇄로 확인한다
